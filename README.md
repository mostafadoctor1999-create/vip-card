# قرية البادية

موقع تعريفي وتجريبي لقرية البادية: أكل ومشروبات وشيشة وجلسات نار للأجواء الباردة.

الرابط المتوقع بعد نشر GitHub Pages:

https://mostafadoctor1999-create.github.io/vip-card/

## الموجود في الصفحة

- نبذة عن القرية وأقسام تعريفية للأكل والمشروبات والشيشة وجلسات النار.
- فلاتر للأقسام؛ لا توجد أصناف أو أسعار منشورة قبل استلام القائمة الفعلية.
- معرض بطاقات توضيحية مؤقتة؛ يلزم إرسال صور حقيقية للقرية لاستبدالها.
- نموذج الحجز يفتح رسالة جاهزة إلى واتساب `+201111815659`. الزائر يراجع الرسالة ويرسلها بنفسه، والطلب لا يعني تأكيد الحجز.
- رابط الاتجاهات: https://maps.app.goo.gl/rNbBHN1eVw8ZaQpr7
- بطاقة ولاء تجريبية لا تحفظ أو ترسل بيانات ولا تحتسب زيارات حقيقية.
- PWA: manifest وService Worker وأيقونة قابلة للتثبيت.

## النشر والتجربة

فعّل GitHub Pages من **Settings → Pages → Deploy from a branch**، واختر `main` والمجلد `/ (root)`. انتظر اكتمال النشر ثم افتح الرابط أعلاه. جرّب أزرار واتساب والاتجاهات، ثم طلب حجز تجريبي. على iPhone استخدم Safari ثم مشاركة → إضافة إلى الشاشة الرئيسية؛ وعلى Android اختر تثبيت التطبيق إذا ظهر الخيار.

## معلومات مطلوبة لاستكمال الهوية والمحتوى

- صور القرية والجلسات والأكل بجودة مناسبة (أرسلها كملفات أو روابط عامة).
- قائمة الطعام والمشروبات والأسعار التي تريد نشرها.
- قواعد بطاقة الولاء الفعلية: الخصم/المكافأة، عدد الزيارات، وكيفية اعتماد الزيارة.

لا يوجد حاليًا نظام خلفي للحجوزات أو بطاقة الولاء؛ الحجز يبدأ برسالة واتساب، والبطاقة للعرض التجريبي فقط.
