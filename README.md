# قرية البادية

موقع تعريفي وتجريبي لقرية البادية: أكل ومشروبات وشيشة وجلسات نار للأجواء الباردة.

الرابط المتوقع بعد تفعيل GitHub Pages:

https://mostafadoctor1999-create.github.io/vip-card/

## ما يعمل في النسخة الحالية

- صفحة تعريفية متوافقة مع الهاتف.
- تصفية أقسام عامة للأكل والمشروبات والشيشة وجلسات النار. لم تُضف أصناف أو أسعار غير مؤكدة.
- نموذج طلب حجز يُنشئ رسالة واتساب، لكنه لا يرسلها إلا بعد أن يراجعها الزائر ويضغط إرسال في واتساب.
- بطاقة ولاء تجريبية محلية لا ترسل أو تحفظ بيانات العميل.
- PWA وService Worker للتثبيت وتخزين ملفات الواجهة الأساسية.
- زر الاتجاهات ورسائل واتساب يحتاجان معلومات القرية قبل تفعيلهما.

## معلومات مطلوبة لإكمال الربط

أرسل:

1. رقم واتساب الخاص بالقرية بصيغة دولية، مثل `+20...` (سأضعه بصيغة أرقام دولية في الرابط).
2. رابط موقع قرية البادية من Google Maps.
3. قائمة الأصناف والأسعار الفعلية، مع تمييز ما إذا كانت الأسعار قابلة للتغيير.
4. شروط الولاء الفعلية: الخصم/المكافأة، عدد الزيارات، وما الذي يُحتسب زيارة.
5. هل تريد استقبال بيانات تسجيل العملاء في Make؟ إن كان نعم، أنشئ Webhook جديدًا بعد إبطال/تدوير القديم، ولا ترسل بيانات حقيقية قبل مراجعة الخصوصية والأمان. الأفضل استخدام وسيط خادمي؛ أي رابط Webhook في HTML سيكون عامًا.

## النشر

من إعدادات المستودع **Settings → Pages**، اختر **Deploy from a branch**، ثم `main` ومجلد الجذر `/ (root)`. انتظر اكتمال النشر ثم افتح الرابط أعلاه عبر HTTPS. على iPhone استخدم Safari ثم مشاركة → إضافة إلى الشاشة الرئيسية؛ على Android استخدم خيار تثبيت التطبيق إذا ظهر.

## ملاحظات

- طلب الحجز ليس تأكيدًا حتى يرد فريق القرية.
- الأسعار والمنيو الحالية غير معروضة كحقائق لأنها لم تُرسل بعد.
- بطاقة الولاء الحالية شكل تجريبي؛ لا توجد قاعدة بيانات أو عدّاد زيارات حقيقي.
- معلومات الموقع ورقم واتساب متروكة بدون إعداد عمدًا، فلا يتم توجيه الزوار إلى رقم أو مكان خاطئ.
