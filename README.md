# قرية البادية

موقع تعريفي وحجز تجريبي لقرية البادية: أكل ومشروبات وشيشة وجلسات نار للأجواء الباردة.

الرابط المتوقع بعد نشر GitHub Pages:

https://mostafadoctor1999-create.github.io/vip-card/

## التحديثات

- تصميم ضيافة راقٍ بلمسات ذهبية ونجوم زخرفية. النجوم عنصر تصميم وليست تقييمًا أو اعتمادًا رسميًا من فئة خمس نجوم.
- أقسام عن القرية والتجربة والأكل والمشروبات والشيشة وجلسات النار، وفلاتر للأقسام.
- بطاقات معرض مؤقتة. أرسل صورًا حقيقية لاستبدالها.
- نموذج الحجز يفتح رسالة جاهزة إلى واتساب `+201111815659`. المستخدم يراجع الرسالة ويرسلها، والطلب غير مؤكد حتى يرد فريق القرية.
- رابط خرائط Google: https://maps.app.goo.gl/rNbBHN1eVw8ZaQpr7
- بطاقة ولاء تجريبية لا تحفظ أو ترسل بيانات ولا تحتسب زيارات فعلية.
- PWA: manifest وService Worker وأيقونة قابلة للتثبيت.

## النشر

من إعدادات المستودع **Settings → Pages → Deploy from a branch**، اختر `main` والمجلد `/ (root)`. بعد اكتمال النشر افتح الرابط أعلاه. على iPhone استخدم Safari ثم مشاركة → إضافة إلى الشاشة الرئيسية؛ وعلى Android اختر تثبيت التطبيق إذا ظهر.

## بيانات ممكن إرسالها لاستكمال الموقع

- صور القرية والجلسات والطعام.
- قائمة الطعام والمشروبات والأسعار التي تريد نشرها.
- شروط برنامج الولاء إن وجد (المكافأة، عدد الزيارات، وآلية احتسابها).

لا يوجد نظام خلفي للحجوزات أو بطاقة الولاء في الوقت الحالي.
