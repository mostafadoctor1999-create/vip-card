# بطاقة الولاء الرقمية — قرية البادية

الموقع يعرض بطاقة ولاء لقرية البادية، مع معلومات عن الأكل والمشروبات والشيشة وجلسات النار. رابط GitHub Pages المتوقع:

https://mostafadoctor1999-create.github.io/vip-card/

## تفعيل GitHub Pages

من إعدادات المستودع افتح **Settings → Pages**، واختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`. انتظر اكتمال النشر وافتح الرابط أعلاه.

## التثبيت والعمل دون إنترنت

أُضيفت ملفات PWA: `manifest.webmanifest` و`sw.js` و`icon.svg`. بعد تفعيل GitHub Pages وفتح الموقع عبر HTTPS، يدعم المتصفح تثبيت البطاقة على الشاشة الرئيسية. على iPhone: افتح الرابط في Safari، ثم مشاركة → إضافة إلى الشاشة الرئيسية. Service Worker يخزن ملفات الواجهة الأساسية؛ التسجيل والمشاركة تحتاج اتصالًا.

## قبل استقبال بيانات حقيقية

- استبدل `TARGET_LAT` و`TARGET_LON` في `index.html` بإحداثيات الموقع الدقيقة للقرية.
- حقل Webhook متروك فارغًا عمدًا؛ أعد إنشاء رابط Make جديد لأن رابط Webhook السابق كان ظاهرًا في الكود والمحادثة. لا ترسل بيانات عملاء حقيقية إلى webhook مكشوف. أي عنوان يوضع في JavaScript العام يمكن للزوار رؤيته؛ الأفضل استخدام وسيط خادمي لحماية نقطة الاستقبال.
- الصفحة في وضع تجريبي محلي حتى إضافة Webhook: تعرض البطاقة ولا ترسل بيانات إلى Make.
- بعد إعداد Make، استخدم بيانات وهمية أولًا، وتأكد من ظهور العملية في سجل التشغيل. الطلب يستخدم `no-cors`، لذلك لا يستطيع المتصفح إثبات أن Make قبل البيانات.
- تحديد الموقع يعمل عبر HTTPS وبعد إذن المستخدم، ويجري مرة واحدة عند التسجيل. حساب النطاق في المتصفح ليس تحققًا آمنًا للخصم؛ تطبيق الخصم الفعلي يحتاج نظامًا يتحقق من البطاقة لدى القرية.
- رمز QR المعروض زخرفي فقط، وختم الزيارات الحالي تصميم توضيحي وليس سجل زيارات حقيقيًا.

## تجربة أولية

1. فعّل GitHub Pages من الخطوات أعلاه وافتح الرابط على الهاتف.
2. سجّل اسمًا ورقمًا تجريبيين، ووافق على مشاركة الموقع. في وضع العرض الحالي لن تُرسل البيانات لأي جهة.
3. جرّب زر المشاركة، ثم جرّب التثبيت من المتصفح.
4. أرسل رابط Google Maps للموقع الدقيق ورابط Webhook جديدًا (بعد تدويره) عند الرغبة في ربط الإحداثيات وMake. لا ترسل بيانات عملاء حقيقية أثناء الاختبار.
